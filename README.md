# Census Tract Eligibility for Opportunity Zone Designation

This code underlies the EIG's estimation of OZ eligibility under the One Big Beautiful Bill Act using 2020-2024 American Community Survey. See our OZ eligibility map [here](https://www.arcgis.com/apps/dashboards/c473c71f0704408f934fbdc342caf1f1). Contact research@eig.org with any questions.
